Coming from Obsidian?

The same files

A vault is a folder of .md files with wiki-links and frontmatter. Point Voidless at an existing vault and keep using Obsidian on your phone — nothing is converted, nothing is locked.

Built in, not bolted on

Databases over folders, drawings, spreadsheets, flashcards with spaced repetition and Drive sync ship with the editor. No plugin hunting, no sync subscription.

What you give up

No plugin ecosystem and no mobile app of our own — the vault is plain files, so any editor opens it. Voidless is younger and moves faster; the file format never does.

The build isn't code-signed yet — Apple/Windows signing is in progress. Until then, the OS may block the first launch. Here's how to allow it:

macOS — first launch

  • Try to open Voidless — macOS blocks it the first time.
  • Go to System Settings → Privacy & Security.
  • Find the "Voidless was blocked" message and click Open Anyway.
  • Confirm Open — it won't ask again.

Windows — first launch

  • SmartScreen may show "Windows protected your PC".
  • Click More info.
  • Click Run anyway.
  • Voidless launches and won't prompt again.
