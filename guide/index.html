Guide

Bold is a button or menu item as it reads on screen. /table is something to type, and → shows what you get: /table → a table. Keys are for Mac; on Windows use Ctrl for ⌘ and Alt for ⌥.

01 Live formatting + ⌘B / ⌘I

Type bold, *italic*, ~~struck~~ → the markup turns into formatting as you type. Select a word → ⌘B makes it bold, ⌘I italic; press again to undo. Put the caret inside a formatted word → the markup shows again, ready to edit.

02 Highlight + wrap a selection

Select a word and press = twice → the word is highlighted. A quote or a backtick typed over a selection wraps it too, instead of replacing it.

03 The / menu + ⌘P palette

Type / on an empty line → everything you can insert. Keep typing to narrow it: /tab → Insert Table → Enter. ⌘P opens the same list plus the app's commands. Try /date and /time → today's date and the time.

04 Find + replace

⌘F → find, with a match count; Enter goes to the next one. ⇧⌘F → replace too: Replace — the current match, All — every one at once; a single ⌘Z takes the whole file back.

05 Tasks + progress

/checkbox → a task. Add a couple more under it and indent them with Tab → the top one gets a bar showing how much is done. Tick one → it sinks below the open ones. Several plain lines at once: select them → ⌘P → Insert Checkbox.

06 Table + cell menu

/table → a table with the caret in its first cell; the arrow keys go into the table from the text and back out. Right-click a cell → rows and columns around it, delete, a link to a note right in the cell, Column settings….

07 Coloured tags + column sort

Right-click a column header → the column window. Add options in Options — say Done, In progress, Planned → Save → cells with those values become coloured tags. In the same window: ↑ Ascending / ↓ Descending (dates and numbers by value), Fill the whole column and the Checkboxes switch.

08 Paste from Excel + move columns

Copy a range in Excel or Google Sheets, click a cell → ⌘V → the range spreads over the cells. Grab the thin strip above a column header and drag sideways → an amber line shows where it lands. Rows move the same way, by the handle on the left.

09 Link to a note + split

/ → Link to page → pick a note → a link button appears at the caret. A click opens the note, ⌘-click in a new tab, ⇧⌘-click beside it in a split. The pencil on the button points it at another note. The file keeps a plain [[note name]], as in Obsidian.

10 Link to a spot + highlight

Select a word → right-click → Link to block… → pick a paragraph or a heading (this note's first, type to search every note) → the word becomes a link with an arrow: ↑ / ↓ — a spot in this note, → — in another one. A click scrolls there and blinks it yellow twice; another note opens in a new tab. The other way round: select some words → right-click → Copy link to these words → paste it anywhere → a click lights up exactly those words. Hover a paragraph that links point to → a faint 🔗 shows where they come from.

11 Link on a word + picture

Select a word and paste a web address → the word becomes a link with ↗; right-click it → edit, unlink, copy. Paste a screenshot with ⌘V → it's saved to the _files folder and shown as a picture; drag the amber square in its corner → it resizes.

12 Alarm + phone

/alarm → Save → an ALARM chip appears in the line; ⚙ on the chip opens it again. At the set time a banner pops up over the editor: Open — go to the line, Snooze 10 min — later. Settings → Editor → Reminders on your phone → Connect → alarms go to a Google calendar of their own and ring on your phone, even with Voidless closed.

13 Note template + variables

Put a note Meeting with the text # Meeting {{date}} in a Templates folder. Settings → Editor → Templates folder → pick that folder. In any note press F1 → Meeting → the template goes in and {{date}} becomes today's date. There's also {{time}}, {{dateRU}} and {{week}}; with Folder templates a template applies to a folder's new notes by itself.

14 Folder fields + fields panel

At the foot of the sidebar → Templates → + New template → folder Tasks, field status with the value [todo, doing, done] → Done. A new note in Tasks gets these fields at once — a panel at the top of the note shows them; a click on doing changes the status. Update Metadata adds the fields to the folder's older notes too.

15 Kanban + drag and drop

Right-click Tasks → New kanban → every status from the template becomes a column. Drag a card to another column → the status in the note changes. + New card under a column makes a note with that status.

16 Card beside the board + table view

Click a card → it opens beside the board, ready to write in; Esc closes it. From the keyboard: arrows move between cards, Space shows or hides a card, ⌥← / ⌥→ moves it to the next column. Right-click a card → move, rename, delete. Table on the board's bar → notes as rows; ▾ in a column header fills that field for all of them, Filter… and Folders narrow the list.

17 Habits + a year at a glance

At the foot of the sidebar → Habits → + new habit → Walk → click the days you did it. The ring on the left shows the month at a glance; Year gives a percentage for every month.

18 Drawing + spreadsheet

/draw → an Excalidraw board right in the note: shapes, arrows, text. /sheet → a spreadsheet with formulas such as =SUM(B1:B3). Both are saved inside the note itself.

19 AI: edit + ask your notes

It needs a key: Settings → Plugins → Claude API key. Select a paragraph → right-click → ✨ AI Improves & Research → tick Improve and Fix grammar → Submit → Insert below, or Show diff… → tick what you want → Apply to note. The AI itself never deletes anything. The Ask your notes tab → What did I plan for October? → Ask: the AI reads your notes and answers with links to them; Save as note keeps the answer.

20 Folding + a note's memory

Click a heading's line number → the section folds (from the keyboard: ⌘⌥[ / ⌘⌥]). Put the caret in the middle of a note, open another and come back → the folds and the caret are where you left them — even after a restart.

21 Lines + code block

⌥↑ / ⌥↓ move a line, and a folded section as a whole; ⇧⌥↑ / ⇧⌥↓ copy it. Three backticks → a code block; hover it → Copy in the corner. Markup doesn't apply inside code: == and ~~ stay as typed.

22 Tabs + per-pane history

Drag a tab along the bar → it changes places; onto another pane's bar → it moves there. The middle mouse button closes a tab and opens a sidebar file in a new one. Right-click a tab → Pin tab → a pin instead of the ×. ⌘⌥← / ⌘⌥→ (or the mouse's side buttons) go back and forward; every pane has its own history.

23 Colour + icon in the sidebar

Right-click a folder or a note → Set color and Set icon → a colour and an emoji by its name. They're stored in the vault itself and move with it to another computer.

24 Sync + conflicts

At the foot of the sidebar → Sync → Connect Google Drive → Sync Now; from then on it syncs at launch and every 5 minutes. Edited one note on two computers? Both versions are kept, and the compare window lets you choose: Keep original, Keep conflict copy or Decide later.

25 Language + look

Settings → Editor → Language: Auto (system), English or Русский; the window reloads. The same tab has font size, interface zoom and line numbers.

26 Updates

At launch Voidless looks for a new version — if there is one, the What's new screen opens: Install now installs it, Skip this release skips it. Open the screen by hand: ⌘P → What's new.
