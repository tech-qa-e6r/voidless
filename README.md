# voidless

Public repo of [Voidless](https://voidless.app), a local Markdown editor for macOS and Windows.

It holds:

- the website [voidless.app](https://voidless.app) — plain HTML/CSS, served by GitHub Pages from `main`;
- the public release builds ([Releases](https://github.com/tech-qa-e6r/voidless/releases)) and the auto-update feed the app checks.

The app's source code lives in a separate repo.

**For everything about the app — guide, changelog, downloads — go to [voidless.app](https://voidless.app).**
